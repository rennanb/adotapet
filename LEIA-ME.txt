AdotaPet | pacote v5
====================

O que muda nesta versao:

1. Botao "Sair" das Configuracoes agora funciona: encerra a sessao no
   Supabase e devolve para a tela de entrada. O painel fica protegido de novo.
2. Paginas novas de Politica de privacidade (/privacidade) e Termos de uso
   (/termos), com texto proprio do projeto, citando LGPD, Brevo, Supabase,
   Vercel, guarda dos dados e direitos de quem se candidata.
3. Links das politicas no rodape da tela de entrada, no modal Sobre e na
   tela de Configuracoes (antes eram links mortos com #).
4. Modal Sobre redesenhado: selo do projeto em formato discreto (sem amarelo
   forte), autores separados do link do GitHub e area de links organizada.
   O link do GitHub aponta para github.com/rennanb/adotapet.
5. Area de exclusao de conta: em vez de um botao que nao fazia nada, agora
   abre um e-mail pronto para pedir a exclusao, igual ao texto da politica.

Como aplicar:
1. Feche o servidor com Ctrl + C.
2. Extraia este zip dentro da pasta do projeto, aceitando substituir.
3. npm run dev
4. No navegador, Ctrl + Shift + R.

Nao precisa de npm install e nao ha SQL novo para rodar no Supabase.
